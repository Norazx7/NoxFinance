# Links obrigatórios — divulgação do NOX FINANCE

Preencha os links reais após publicar. Não invente URLs.

| Item | Status | Link / caminho |
|------|--------|----------------|
| Repositório GitHub | Pendente de publicação pública | `https://github.com/<seu-usuario>/nox-finance` |
| Post no LinkedIn | Texto pronto; publicação pendente | Cole a URL do post após publicar |
| Arquivo do Roteiro de Extensão (DOCX) | Pronto | `docs/extensao/NOX_FINANCE_Roteiro_de_Extensao.docx` |
| Arquivo do Roteiro de Extensão (PDF) | Pronto | `docs/extensao/NOX_FINANCE_Roteiro_de_Extensao.pdf` |
| Cópia para entrega/anexo | Pronto | `docs/divulgacao/arquivos/NOX_FINANCE_Roteiro_de_Extensao.docx` |
| Print do post LinkedIn | Pendente | `docs/divulgacao/evidencias/print_post_linkedin.png` |

## GitHub

Este projeto ainda precisa ser publicado em um repositório GitHub público/privado acadêmico.

1. No Cursor, use **Create repo** para criar o repositório.
2. Copie a URL resultante (exemplo de formato: `https://github.com/seu-usuario/nox-finance`).
3. Cole abaixo:

```text
GITHUB_URL=
```

4. Atualize também o post em `POST_LINKEDIN_NOX_FINANCE.md`.

## LinkedIn

1. Abra `POST_LINKEDIN_NOX_FINANCE.md`.
2. Cole o texto no LinkedIn com o link do GitHub.
3. Após publicar, cole a URL do post:

```text
LINKEDIN_POST_URL=
```
